# xtaledit

Evaluates the novelty of inorganic crystal structures generated by AI. See README.md for the classification scheme.

## Environment

```bash
uv venv && source .venv/bin/activate
uv sync --group dev
```

## Commands

```bash
# Lint + fix imports + format (run in this order)
ruff check --fix .
ruff format .

# Preprocess structures (primitive + Niggli reduction)
python scripts/preprocess.py

# Tests
pytest

# Install pre-commit hooks (once per clone)
pre-commit install
```

## Slash commands

- `/commit` — stage → analyze diff → write commit message → commit → push

## Code style

- Line length: 88
- Import sorting: handled by ruff (`I` rules). isort is installed only for editor compatibility — do not add it as a separate CI step.
- Run `ruff check --fix` before `ruff format` (fixing first avoids format churn).
- Target Python 3.12. Use `match`, `TypeAlias`, `type X = ...` where natural.
- Docstring style: Google style.
- Tests live in `tests/`. Prefix test files with `test_`.

## Directory layout

```
input/
├── gen/
│   ├── raw/           # AI-generated structures, as-generated
│   └── preprocessed/  # After cleaning/normalization
└── train/
    ├── raw/           # Original training structures
    └── preprocessed/  # After cleaning/normalization

results/               # Evaluation outputs (intermediate results, derived structures)
```
