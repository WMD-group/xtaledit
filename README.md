# xtaledit

Evaluates the novelty of inorganic crystal structures generated by AI models, by comparing them against a training dataset.

## Novelty classification

Each AI-generated structure is assigned to one of three categories:

| Category | Description |
|----------|-------------|
| **1** | Matches a training structure directly via `StructureMatcher` |
| **2** | Does not match directly, but matches after element-type substitution on a training structure followed by structural relaxation |
| **3** | Matches neither — considered genuinely novel |

## Setup and usage

Scripts take one YAML configuration path:

```bash
python scripts/exact_match.py configs/crystalite/02_exact_match.yaml
```

The ordered files in `configs/crystalite/` reproduce the Crystalite pipeline
outputs in `results/raw/crystalite/`. Paths in configuration files are resolved
relative to the repository root.

See [AGENTS.md](AGENTS.md) for environment setup, commands, and code style.
