# xtaledit

## Project purpose

`xtaledit` evaluates the novelty of inorganic crystal structures generated by AI
models by comparing them against a training dataset.

Novelty categories:

- Category 1: direct match to a training structure via `StructureMatcher`.
- Category 2: no direct match, but matches after element-type substitution on a
  training structure followed by structural relaxation.
- Category 3: no match; considered genuinely novel.

## Environment

```bash
rtk uv venv
source .venv/bin/activate
rtk uv sync --group dev
```

## Commands

Run shell commands through `rtk`.

```bash
# Lint, fix imports, then format. Run in this order.
rtk ruff check --fix .
rtk ruff format .

# Tests
rtk pytest

# Preprocess structures: primitive + Niggli reduction
rtk python scripts/preprocess.py configs/crystalite/01_preprocess.yaml

# Install pre-commit hooks once per clone
rtk pre-commit install
```

## Code style

- Target Python 3.12. Use `match`, `TypeAlias`, and `type X = ...` where natural.
- Keep line length at 88 characters.
- Use Google-style docstrings.
- Tests live in `tests/`; prefix test files with `test_`.
- Import sorting is handled by Ruff `I` rules. `isort` is installed only for
  editor compatibility; do not add it as a separate CI step.
- Run `rtk ruff check --fix .` before `rtk ruff format .` to avoid format churn.

## Directory layout

```text
input/
├── gen/
│   ├── raw/           # AI-generated structures, as-generated
│   └── preprocessed/  # After cleaning/normalization
└── train/
    ├── raw/           # Original training structures
    └── preprocessed/  # After cleaning/normalization

results/
├── raw/               # Script outputs and intermediate evaluation artifacts
└── analysis/          # Notebook figures, tables, and derived structures
```
